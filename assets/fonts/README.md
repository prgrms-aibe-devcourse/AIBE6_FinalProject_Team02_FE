# 원본 폰트

`온글잎 딩궁딩굴.ttf` (5.86MB) — 앱 전체 글꼴의 원본이다.

## 클론만 한 사람은 이 파일이 없다. 그래도 정상이다

**받아 둘 필요 없다.** 앱이 쓰는 건 잘라 놓은 `public/fonts/*.woff2`이고 그건 커밋돼 있다.

원본을 지운 상태로 검증한 결과다.

| 확인                         | 결과                                                              |
| ---------------------------- | ----------------------------------------------------------------- |
| `npm run build`              | 통과                                                              |
| 화면에 딩궁딩굴로 그려지는가 | **그려진다** (같은 글자 폭 178.3px / Pretendard 폴백이면 268.8px) |
| 받아 가는 파일               | `dinggul-0.woff2` 하나                                            |
| `npm run build:font`         | 원본이 필요하다고 안내하고 멈춘다                                 |

**한글 11,172자 전부**가 71조각에 들어 있고 조각 간 중복도 없다(검증). 어떤 음식 이름·닉네임이
와도 글자가 빠지지 않는다.

## 이 파일은 git에 올리지 않는다

`.gitignore`로 제외돼 있다. 두 가지 이유다.

1. **5.86MB.** 저장소 전체가 4.6MB인데 원본 하나로 두 배가 넘는다.
   런타임에 필요한 건 잘라 놓은 `public/fonts/*.woff2`뿐이고 그건 커밋한다.
2. **제3자 폰트의 원본 파일**이라 재배포 조건이 웹 임베딩과 다를 수 있다.

## 다시 만들어야 할 때

받는 곳: https://www.ownglyph.com (온글잎 딩궁딩굴)

```bash
# 이 폴더에 원본 이름 그대로 두고
npm run build:font
```

`public/fonts/dinggul-*.woff2` 71개와 `src/app/fonts.css`가 다시 생성된다.
**둘 다 커밋한다** — 생성물이지만 런타임에 필요하다.

## 다시 만들어야 하는 경우

- 폰트 원본이 갱신됐을 때
- **`src/`에 새로운 한글이 많이 들어갔을 때.** 0번 조각은 소스에 등장하는 글자로 만들어져서,
  새 문구가 늘면 그만큼 다른 조각을 더 받게 된다. 화면 문구를 크게 손봤으면 한 번 돌린다.
  (안 돌려도 글자는 정상적으로 보인다 — 받는 조각 수만 늘 뿐이다)

## 라이선스 — 확인 완료 (2026-08-11)

제공처: **온글잎(Ownglyph) / VoyagerX, inc.** — https://www.ownglyph.com

> 온글잎에서 제작해서 배포하는 모든 폰트는 영리적, 상업적 사용을 포함하여 모든 용도에
> 아무 제한 없이 사용할 수 있어요. 그리고 폰트 파일을 설치할 수 있는 모든 기기와
> 운영체제에서 사용할 수 있습니다. 당연히 웹폰트, 임베딩도 가능합니다.

이 앱이 하는 일이 그 범위 안에 있다.

| 우리가 하는 것 | 허용 근거 |
|---|---|
| 웹폰트로 자체 호스팅 (`public/fonts/*.woff2`) | "웹폰트, 임베딩도 가능" |
| 상업 서비스에 사용 | "영리적, 상업적 사용을 포함하여" |
| 서브셋으로 잘라 woff2로 변환 | "모든 용도에 아무 제한 없이" — 웹폰트를 쓰려면 필요한 통상적 가공이다 |

폰트 파일의 `fsType`도 `0`(임베딩 제한 없음)이라 기술적으로도 막히지 않는다.

**팀에 남길 것** — 위 인용은 사본이라 그 자체가 증빙은 아니다. 배포 전에 온글잎 이용약관
페이지 **URL이나 캡처**를 이슈·위키에 한 번 붙여 두면 나중에 다시 찾지 않아도 된다.
